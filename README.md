# FBG 光纤传感实验：数据分析脚本与原始数据

大连理工大学 物理创新实验报告（2026 秋）· 本仓库是**实验分支**（`fbg-fiber-sensing-calibration`），索引见 [`main`](https://github.com/xzx-001/dlut-physical-exp/tree/main) 分支。

光纤布拉格光栅（FBG）两组测量的**原始记录与数据处理脚本**，可以独立运行、
复现实验报告中的全部数值与图。报告正文（LaTeX）不在本仓库内。

- **位移（应变）组**：PE-100-A 激光三角位移计与 Rainbow 光纤光栅解调仪并联，
  以毫米刻度尺为参考，10–60 mm 内每 5 mm 一组（正程 11 点、反程 11 点），
  另有 4 个未参与拟合的验证点（23、38、47、54 mm）。
- **温度组**：封装 FBG 与两线制 PT100（经 AI-501 变送）一同插入恒温加热器，
  30 s 周期采集升温过程，另有一段降温记录。

两组使用**两只不同的光栅**、不同参考量具与采集方式，因此标定系数只对本组成立，
**不做跨组换算**。

| 项 | 结果 |
|---|---|

| FBG 主测峰标定 | 10.298 pm/mm，R² = 0.999081，残差 rms 5.2 pm（≈0.50 mm 位移当量） |

| 温度稳定段 | 26.2–54.9 °C 共 16 点，全段线性 K_T = 9.75 ± 0.81 pm/°C（R² = 0.9124） |

## 运行

```bash
pip install -r requirements.txt

# 全部数值 + 数据图（默认写到 output/）
python3 scripts/analyze.py

# 示意图（analyze.py 已连同 MCMC 图一起出；下面两张单独跑）
python3 scripts/plot_models.py      # 温度稳定段六种拟合模型对比
python3 scripts/plot_clamp.py       # 夹持几何剖面

# 取峰偏差分析（可选，需先有光谱截图；按依赖顺序跑）
python3 scripts/digitize_spectrum.py
python3 scripts/sim_real_profile.py && python3 scripts/plot_bias.py

# 指定输出目录
python3 scripts/analyze.py --figures ../figures --results ../results
```

依赖：Python 3.9+、NumPy、Matplotlib；中文标注需要系统里有 SimHei 字体
（无此字体时可把脚本里的 `font.sans-serif` 改成 `Noto Sans CJK SC` 等）。

MCMC 用固定随机种子（3 条链 × 60000 步，弃前 15000 步，每 10 步取一个样本，
共 13500 个后验样本），因此结果可完全重放。

## 数据说明

CSV 为逐周期导出的原始表（位移组 41 列、温度组 30 列），分析只用到少数几列：

| 组 | 关键列 | 含义 |
|---|---|---|
| 位移组 | `pe_raw_value` | PE 激光位移计原始输出（count，未标定） |
| 位移组 | `fbg_peak1_nm` / `fbg_peak2_nm` | 解调仪报告的峰值 1 / 峰值 2 中心波长（nm） |
| 位移组 | `cycle_status` | `complete` / `partial`，用于剔除缺峰周期 |
| 温度组 | `pt100_temperature_c` | PT100 经变送器换算的温度（°C） |
| 温度组 | `fbg_peak1_nm` / `fbg_peak2_nm` | 同上；**列号不等于峰身份**，见下文「处理要点」 |

## 处理要点

- **峰位跳变判据**：相邻两点单列波长差 > 500 pm 即标记（本温区真实热漂移上限约
  0.4 nm）；标记后不自动处置，需结合两峰间距与相邻列交叉逐行判断——整对峰重新
  锁定的行剔除，波长连续而传感峰只换了列的行（第 21–23 行）保留。
- **稳定段**：升温记录第 3–20 行，排除第 13 行（两列同向单点偏移）与第 8 行
  （partial），共 16 点。
- **重复性**：正反程在同一参考位置作差 $\Delta S = S_\text{正} - S_\text{反}$，
  只作为"观察到的差值"报告；本实验分辨率下不能判定为传感器迟滞。
- **温度模型的边界**：全段线性只是把弯曲数据拟成直线后的平均值；分段与二次拟合
  的结果差异说明单一 K_T 不适用，这与"夹持应变随温度变化"一致。

## 边界与免责

- 位移组给出的是**"波长—参考位置"标定关系**，不是真实应变：换算应变需要梁长、
  截面、加载与粘贴位置等几何参数，本次未记录。
- 夹持几何（光纤斜穿竖直圆孔，与上孔口棱边 A、下孔口棱边 B 两点相切）为**示意**：
  插入角未实测，只按"小倾角分支"作图（x=R_h/r_f=1.15，θ≈4.9°，ε_b=0.042%）——该分支
  是唯一与"光纤不断裂"相容的一支（θ>45° 要求 ε_b≳5%，远超 0.2% 许用值）。
- 数据来自课程实验当场采集，仅用于教学与方法演示。
