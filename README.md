# PECVD 生长尝试与机械剥离石墨烯的拉曼光谱：原始数据与处理脚本

大连理工大学 物理创新实验报告（2026 秋）· 本仓库是**实验分支**（`pecvd-graphene-raman`），索引见 [`main`](https://github.com/xzx-001/dlut-physical-exp/tree/main) 分支。

实验分两部分：前端预加热式 PECVD 的生长尝试（**未获得可供表征的产物**，未对生长衬底采谱），
以及改用**胶带机械剥离**石墨烯后的拉曼表征（三个测量位置 S1–S3）。

本仓库含 4 条原始光谱（3 条样品谱 + 1 条硅标准样）与全部处理 / 绘图 / 消融脚本，
可复现结果中的全部数值与图。**报告正文（LaTeX）不在本仓库内。**

> **读数前提**：以下全部数值均属**机械剥离样品**，不代表 PECVD 生长产物。

## 复现

依赖 Python 3.9+、NumPy、SciPy、Matplotlib；中文标注需要系统里有 SimHei 字体
（脚本已按 `SimHei → Noto Sans CJK SC → WenQuanYi Zen Hei → DejaVu Sans` 顺序回退）。

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt

.venv/bin/python scripts/analyze.py     # → results/summary.json、results/arrays.npz
.venv/bin/python scripts/ablation.py    # → results/ablation.json（消融实验）
.venv/bin/python scripts/plot.py        # → figures/fig01–fig06（PDF + PNG）
```

`plot.py` 读 `results/arrays.npz`，因此必须在 `analyze.py` 之后运行。三个脚本只读 `data/raw/`，
不写回原始数据；结果文件覆盖生成，仓库中已附带一份，重跑得到的数值与之一致。

脚本用 `Path(__file__)` 推导仓库根，克隆后无需改动路径即可运行。

## 数据说明

文件为两列 ASCII（第一列拉曼位移 cm⁻¹、第二列强度 counts），仪器导出的 CRLF 换行、
首行可能带 UTF-8 BOM，`raman_io.load_spectrum` 已统一处理并按位移升序返回。
三条石墨烯谱的位移网格完全相同（逐点相减为 0），可逐点平均。

## 处理要点

1. **空气拉曼线（关键）**：每条谱在 1554 cm⁻¹ 与 2330 cm⁻¹ 各有一个 6–7 cm⁻¹ 宽的对称峰，
   位置与样品无关 → 判为光路中空气的 O₂（1554.6）与 N₂（2330.7）气体拉曼线。
   判据：① 峰位与公认值吻合（偏差 +0.09 / −1.02 cm⁻¹）；② 两线强度比 3.78–4.26，
   与空气 N₂:O₂ = 78:21 ≈ 3.7 相符；③ 不建模 O₂ 时 G 带窗口残差 rms 由 15–21 升至 30–33 counts
   （复算见 `scripts/ablation.py`）。处理方式是**不剔除**：O₂ 作为 G 带窗口内的第二个洛伦兹分量，
   N₂ 在 2300–2360 单独拟合。不要沿用「2330 是探测器坏列」的旧结论——坏列不会给出对称洛伦兹线型，
   也不会与 O₂ 保持空气组成比。
2. **基线**：Eilers 非对称最小二乘，λ = 1e6，p = 0.003，迭代 15 次。
3. **峰参数**：G 带窗口 1525–1615（O₂ + G 两分量）、2D 带 2560–2790（两分量），
   洛伦兹型 + 线性基线。D′ 带（1600–1690）试拟合退化（峰高为负、误差大于数值）→ 判为不可分辨。
4. **D 带区**：1300–1460 只有宽弱鼓包，多点洛伦兹退化，改用两端连线基线 + 7 点平滑统计
   （峰高 29–37，窗口噪声 14.0–15.4，平滑后 8.7–11.6），`D_is_resolved = false`。

## 边界与免责

- **生长部分没有产物**：本批未对生长衬底采拉曼谱，因此不存在「生长产物 vs 剥离样品」的对比；
  谱中的碳源（CH₄）判据亦不可用（测量在另一台设备、另一天、大气环境下完成）。
- **层数判据有上限**：2D 带分量数、$I_{2D}/I_G$ 组合只能判到「多层、趋向石墨态」，不能给精确层数。
- **D 带只给上限**：鼓包未分辨，$I_D/I_G$ 为峰高比而非积分强度比。
- **缺失的采集参数**：采集时间、物镜倍数、光斑尺寸与到达样品功率均未记录；激发波长 532 nm 由实验记录确认。
- 数据来自课程实验当场采集，仅用于教学与方法演示。
